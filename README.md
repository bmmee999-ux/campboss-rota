# ตารางเวรพนักงาน (ออนไลน์ ใช้ Supabase)

ไฟล์ในโฟลเดอร์นี้
- `index.html`  ตัวเว็บ (ไม่ต้องแก้)
- `config.js`   ใส่ URL และ key ของ Supabase (แก้ไฟล์นี้ไฟล์เดียว)
- `setup.sql`   สร้างตาราง (ทำไปแล้วในขั้นก่อน รันซ้ำได้)
- `seed-data.sql`  ย้ายข้อมูลปัจจุบันเข้า Supabase

## ขั้นตอน
1. ใส่ URL และ key ใน `config.js` แล้วบันทึก
2. เปิด `index.html` ในเบราว์เซอร์ → แถบบนต้องขึ้น 🟢 ออนไลน์
3. (ถ้าต้องการข้อมูลเดิม) วาง `seed-data.sql` ใน Supabase > SQL Editor แล้ว Run จากนั้นรีเฟรชหน้าเว็บ
4. ไปที่ https://app.netlify.com/drop ลากโฟลเดอร์นี้ไปวาง → ได้ลิงก์ให้ทีมใช้
   (โฟลเดอร์ต้องมี index.html และ config.js)

## ระบบบันทึก (สำคัญ)
- การแก้ไขทุกอย่าง (จัดเวรอัตโนมัติ เลือกชื่อ ลบ ฯลฯ) เป็น **ร่างในเครื่องที่แก้เท่านั้น** ตารางที่ทีมเห็นไม่เปลี่ยน จนกว่าจะกดปุ่ม **💾 บันทึก** ที่แถบด้านบน
- ถ้าแก้ผิด กด **↩ ยกเลิกการแก้ไข** กลับเป็นตารางที่บันทึกไว้ล่าสุด
- ปิดหน้าโดยไม่บันทึก: เปิดใหม่ระบบกู้ร่างให้ (เฉพาะเครื่องเดิม)
- ถ้ามีคนอื่นบันทึกใหม่กว่าระหว่างที่คุณแก้ จะขึ้นเตือน ต้องกดบันทึกซ้ำอีกครั้งเพื่อบันทึกทับ
- ตั้ง `PIN` ใน `config.js` ได้ ถ้าไม่อยากให้พนักงานทั่วไปกดบันทึกได้ (เป็นการกันกดพลาดเท่านั้น ไม่ใช่ระบบความปลอดภัยเต็มรูปแบบ)

## สถิติรายเดือน
ทุกครั้งที่กดบันทึก ระบบเก็บสถิติรายเดือนของพนักงานทุกคน (รอบโอที ชั่วโมง เวรวันหยุด วันลา และจำนวนครั้งแยกตามหน้าที่) ดูย้อนหลังได้ที่เมนู **สถิติย้อนหลัง** เลือกเดือน หรือ "รวมทุกเดือน (สะสม)" และมีในไฟล์ Export Excel (แท็บ "สถิติรายเดือน")

## การใช้งานของทีม
- ใครมีลิงก์ก็เปิดดูได้ ข้อมูลที่บันทึกแล้วตรงกันทุกเครื่อง (อัปเดตทุก 10 วินาที ถ้าเครื่องนั้นไม่มีร่างค้าง)
- แถบด้านบน: 🟢 ออนไลน์ = ปกติ / 🟡 กำลังเชื่อมต่อ / 🔴 ยังไม่ได้ตั้งค่า config.js
- ไม่มีรหัสผ่าน อย่าโพสต์ลิงก์ในที่สาธารณะ

## กู้ข้อมูลเมื่อมีคนแก้ผิด (สำรองอัตโนมัติรายวัน)
ทุกครั้งที่บันทึก ระบบเก็บสำเนาของวันนั้นไว้ในแถว `bk-วันที่` ของตาราง `app_state`
ถ้าต้องการย้อนกลับไปวันที่ 2026-10-30 ให้รันใน SQL Editor:
```sql
update app_state set data = (select data from app_state where id = 'bk-2026-10-30'), updated_at = now() where id = 'main';
```
(ดูรายชื่อวันที่มีสำเนาได้ที่ Table Editor > app_state) แล้วให้ทุกคนรีเฟรชหน้าเว็บ
นอกจากนี้ควรกด Export Excel เก็บสำรองเป็นระยะ
